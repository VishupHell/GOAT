# Требования безопасности

| ID    | Требование                                                                                                                         | Критерий приёмки                                                                                                                                           | Связанные T / D (позднее) |
|-------|------------------------------------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------|---------------------------|
| SR-01 | Созданные задачи, их статус и описание доступны только участникам команды                                                          | При обращении пользователя к списку задач команды, участником которой он не является, система отклоняет запрос                                             | —                         |
| SR-02 | Член команды, не являющийся ни исполнителем задачи, ни администратором этой команды, имеет право только просматривать детали задач | При попытке изменить какие-либо данные задачи, в которой участник не является исполнителем и не является администратором команды, система отклоняет запрос | —                         |
| SR-03 | Не администратор команды не может создать задачу в этой команде                                                                    | При попытке создать задачу не администратором команды система отклоняет запрос                                                                             | —                         |
| SR-04 | Команду может создать только зарегистрированный пользователь                                                                       | При попытке незарегистрированного пользователя  создать команду, система отклоняет запрос                                                                  | —                         |
| SR-05 | Только администратор команды может приглашать пользователей в эту команду                                                          | При попытке обычным участником команды пригласить пользователей в свою команду, система отклоняет запрос                                                   | —                         |
| SR-06 | Только администратор команды может удалять пользователей из команды                                                                | При попытке обычным участником команды удалить пользователей из команды, система отклоняет запрос                                                          | —                         |
| SR-07 | Только администратор команды может удалять задачи                                                                                  | При попытке обычным участником команды удалить задачу, система отклоняет запрос                                                                            | —                         |
